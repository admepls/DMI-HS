# N16R8 installer support — 2026-10-20

## Changes

- Added ESP32-S3 N16R8 (16 MB flash, 8 MB octal PSRAM) as recommended hardware,
  retaining classic ESP32 / 4 MB as an explicit choice.
- Added a public, immutable catalog shared by browser and backend in
  `functions/firmware-targets.mjs`. N16R8 uses bootloader offset `0x0000`,
  partitions `0x8000`, and factory app `0x20000`; classic retains `0x1000`,
  `0x8000`, and `0x20000`.
- The backend validates hardware IDs, reads N16R8 releases only from `n16r8/`,
  requires matching N16R8 metadata, checks all three binaries exist, and signs
  only allowlisted paths. Classic callers without a target remain compatible.
  Existing authorization, IP/account/global quotas, and success reporting remain.
- The browser requires hardware selection, checks the returned target/chip family,
  invalidates prepared links on selection change, and blocks selection or another
  preparation while a flash dialog is open. No arbitrary S3 variant is advertised.
- Added recommendation/specification copy, N16R8 USB-to-UART guidance, and
  matching target information on the release card/board illustration.
- Pages now includes only the public hardware catalog from the functions folder.
  It does not publish backend code, environment files, or firmware binaries.
- Added an intentionally unpublished N16R8 release template and README rollout
  instructions. Corrected the tablet flash-instruction grid overflow found in QA.
