  2. 02

    Connect

    Select the ESP32

    Complete step 1

    Prepare the protected files, connect the board by USB, then select its COM port when prompted.

    Web Serial is unavailable. Please switch to desktop Chrome or Edge.
    Secure download links expire after a few minutes.

    Full installation

    Bootloader, partitions, and firmware will be written together.

    Existing ESP32 data will be erased.
    Please switch to desktop Chrome or Edge. Open this page over HTTPS or from localhost.
  3. 03

    Flash protocol

    Enter download mode

    Waiting for connection
    ESP32 BOOT RESET/EN

    The BOOT sequence activates when the installer opens.

    1. Hold BOOT when “Preparing installation” appears.
    2. Tap RESET/EN while continuing to hold BOOT.
    3. Release BOOT when “Erasing” begins.

    Keep the USB cable connected until installation completes.
